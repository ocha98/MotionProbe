# MotionProbe（モーション確認ツール）

> このツールは [Claude Code](https://claude.com/claude-code)（AnthropicのAIコーディングエージェント）を使って作成されました。

AIエージェントが、VRChatアバターの「動き」を把握するためのUnityエディタ拡張です。
髪・スカート・尻尾・耳などの揺れもの（PhysBone）や、ダンス・エモートなどのアニメーションを記録し、
AIが読める形（数値のレポートと画像）にまとめます。

## 何をするのか

1. 再生モードに入り、アバターを決まった動きで動かします（歩く・止まる・ターン・ジャンプ・揺らす、パラメータのON/OFFなど）。
2. 時間を1/60秒刻みに固定して記録します。何度やっても同じ結果になるので、設定変更の前後を比べられます。
3. 全身と頭部を、正面・横・背面から同じ瞬間に撮影します。
4. 揺れものを1本ずつ測ります（揺れ幅・収まるまでの秒数・震え・コライダーへのめり込み）。ダンスの繰り返し周期も検出します。
5. レポートと画像を `MotionProbeRuns/` フォルダに保存し、再生モードを自動で終了します。

1回あたり15〜40秒ほどかかります。エディタ専用なので、アバターのアップロードには含まれません。

## AIへの頼み方（例）

- 「髪の揺れが自然か確認して」
- 「スカートが脚にめり込んでいないか見て」
- 「このダンス（パラメータ名 DoodleDance）がどんな動きか教えて」
- 「耳の揺れを少し落ち着かせて、変更前と後を比べて」

AIは結果を見て「どの部分が、何秒後に、何cm、どちらへ動いたか」を説明します。
同じ画像は `MotionProbeRuns/<実行日時>/` にあるので、自分の目でも確認できます。

## 出力されるもの

| ファイル | 内容 |
|---|---|
| `report.md` | 数値のレポート（AI向け、英語） |
| `sheet_body.png` / `sheet_head.png` | 全身・頭部のコマ割り画像（行＝正面/横/背面、列＝揺れが大きい瞬間など） |
| `trail_physbone.png` | 揺れものグループごとに、先端の軌跡を拡大した図（色＝時間） |
| `chart.png` | 揺れの大きさと体の速さの時間変化のグラフ |
| `sheet_cycle.png` / `trail_cycle.png` | ダンスなど繰り返す動きの1周期分（検出できたときだけ） |

## 必要なもの

- VRChat Avatars SDK のプロジェクト（ないプロジェクトでは、このツールは自動で無効になります）
- Gesture Manager（パラメータのON/OFFに使用。なくても移動系のテストはできます）
- AIとUnityをつなぐ「MCP for Unity」（あれば `motion_probe` というツールとして登録されます）

VCC（VRChat Creator Companion）に次のリポジトリを追加すると、プロジェクトの「Manage Project」から入れられます。

- https://ocha98.github.io/MotionProbe/index.json

`Assets/MotionProbe` に旧版（unitypackage版）が入っているプロジェクトでは、先にそのフォルダを削除してください。両方あると重複エラーになります。

## できないこと

- **歩くときの脚の動き。** VRChatの歩行アニメーションは、Unity内では1ポーズだけの仮のものなので、脚は止まったままになります。移動と停止による揺れものの慣性は正しく再現されます。
- **メッシュ同士のめり込み判定。** めり込みは揺れもののコライダーに対してだけ測ります。服が体を突き抜けて見えるかどうかは、画像で確認してください。
- **「自然に見えるか」の最終判断。** 数値と画像で問題点を示すところまではAIができますが、好みの判断は人が行います。
